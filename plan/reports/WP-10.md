## Deviations / decisions
- `normalize_text` also collapses whitespace (interfaces.md section 5); `comparable` = `normalize_text` casefolded.
  Glyph and invisible-char sets are imported from `ingest` (WP-09), with a local fallback copy.
- `script_source_issues` returns only the new `script` issues (ids numbered after the non-script ones) and skips one
  when an AI issue of the same kind already covers the same item IDs. `apply_script_issues` does the idempotent
  replace (drop old script issues, renumber, append). Commands use it, so `build_profile` returns AI issues only
  (needed for golden equality; the golden has no phone, so `profile-build` adds an info `missing_contact`).
- Education ending inside a full-time (`employee`) range is `info`; real work overlaps >= 2 months are `warn`,
  touching/1-month overlaps `info`. Language list is the module constant `PROGRAMMING_LANGUAGES`.
- Verbatim checks also cover `basics.name`, `basics.label`, `basics.email` (whole CV), and education institution;
  `build_profile` `not_verbatim` covers name, email, employer, title, `date_text`, client, role label, institution,
  certificate. Work `location`, skill labels and other-section titles are not checked in the build step.
- Skill keyword splitting ignores separators inside brackets (`Cloud (AWS, GCP)` stays one keyword); the leading
  `Label:` is stripped only when the group has a `name`.
- On `profile-verify` violations the renumbered profile is still written back (so violation IDs match the file),
  but the artifact is recorded and stage advanced only on success; failures set `status: failed`.
- `profile-show` outline is capped by the shared 15-line cap; `--all` also lists highlights, all issues and attestations.
- `export-jsonresume` omits `endDate` for `present`, maps country to `location.countryCode`, and drops
  `other_sections` (no JSON Resume equivalent).
- Violation `item_id` for `unmapped_line` is `L<n>`; for map problems it is the item ID being built.
