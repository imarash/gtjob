## Behavior notes
- Dropped IDs cover bullets, certification IDs and skill-group IDs. An engagement left with no bullets folds into
  `collapsed_line` (`Also: A (Role) · B (Role)`).
- `render` stage rule: stage < `approved` forces draft and leaves the stage alone. Stage ≥ `approved` moves to `rendered`.
- `--pages` is view-only. It makes no `state.json` write, no rebuild and no staleness change. It uses `pdftoppm
  -singlefile`, else Typst PNG from `build/cv.typ`. Tests cover a validated run staying validated, exit 4 with no
  `cv.pdf`, and exit 2 for an out-of-range page.
- `fit.json` is used only when it is schema-valid and `tailored_version` matches. Otherwise the run is unfitted:
  density `standard`, no drops, and the warning "not fitted; run cvt fit".
- `render_run(out_pdf=...)` (for `cvt fit` trial compiles) leaves `cv.md` and `pages/` alone.
  It accepts explicit `dropped_ids` and `density`. I added a `ppi` kwarg and extra `RenderResult` fields with defaults.
- Template choice: `--template`, else `tailored.target.template`, else `state.options.template`.
  `classic` exits 2 "template 'classic' not installed" until WP-17 lands; the test follows the file's presence.

## Deviations
1. **Semibold font**: `FONTS.md` says Semibold is a separate family "Source Sans 3 Semibold". Typst 0.15 (CLI and wheel)
   registers it as weight 600 inside "Source Sans 3", and the separate family name warns "unknown font family". The
   templates use `weight: 600`. WP-02 may want to correct `FONTS.md`.
2. **Dates alignment**: the brief says "use a grid". I used one paragraph with `h(1fr)` per line instead.
   Both give a single line with `pdftotext -layout` (the test asserts this). Raw `pdftotext` (no `-layout`) splits
   at the large gap either way, and the paragraph form was no worse.
3. **Section titles**: `upper()` with tracking instead of `smallcaps`. `smallcaps` extracts as "S ummary", which would
   break ATS section detection.
4. **Section order**: fixed, because `target.emphasis` is free text and not machine-readable. Contract section 9 says
   "unless emphasis says otherwise", so a structured emphasis field would be needed for reordering.
5. **Certifications** render as one inline paragraph separated by ` · ` (saves space). Earlier experience renders one
   line per item as `Employer — Title (YYYY)` (a year range when the years differ).
6. Education dates show only `end_date`, because `tailored.education` has no start date.
