  topic is one question. I counted strategy as three questions (template, emphasis, earlier-experience line), which
  gives exactly 8: 1 gap + 1 merged source issue + 3 metric + 3 strategy.
- The `cvt questions --add` file shape is not specified in the contracts. I documented it as the same shape as
  `questions.json` (ids are renumbered by the script) and validated the example against `questions.schema.json`.
- "Skip the rest" is shown as one `action: skip` item per pending question (the schema ties `skip` to a
  `question_id`).
- Candidate-specific profile ids (`exp-2.e4`, `exp-5`, ...) are used in examples as the brief requires; employer
  and client names are replaced by descriptors in prose.
- The tailor example places SLO / error-budget attestations (placement `bullets`) only in a bullet, never in the
  skills block, per truthfulness rule 3.
