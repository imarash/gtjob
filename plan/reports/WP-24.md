- **`gtjob` CLI is a stub.** `src/gtjob/cli.py` currently prints "not implemented yet (WP-22)" and exits 7. The README
  documents the planned `gtjob tailor`, `gtjob continue`, `--auto`, `--answers`, and `--jd-url` interface from
  interfaces.md section 12 and marks it as not yet available. The README also gives the working `cvt` commands for the
  scripted steps.
- **No PNG previews.** `.cache/test-artifacts/` exists but is empty, so the Templates section describes `modern`
  (default) and `classic` and shows how to produce previews with `cvt render latest --png`. Nothing was copied into
  `docs/img/`.
- **Claims verified against code, not only the contract:** the scanned-PDF error is `E_CV_SCANNED` (exit 5), the
  Typst error is `E_TYPST_MISSING` (exit 3), and the fit error is `E_FIT_OVERFLOW` (exit 1). The docs use these
  messages verbatim.
- **Evals.** Only `evals/triggers.yaml` exists; there is no live-eval runner yet. The README says so.
