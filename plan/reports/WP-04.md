## Deviations

- The brief says Brightfield is "2024-present" and the intern role "2023". To get the required 2-month overlap
  with the BSc (ends Aug 2023), the intern role is Jul 2023 - Dec 2023 and the BSc is dated Aug 2023. Brightfield
  is Feb 2024 - Present.
- `cert-1` has no date (the CV line is just the certification name), so `date` is `""`.
- Every `tailored.json` skill item carries a resolved ref (profile `skl-N`, or `att-001` for Helm), while the plan
  has empty `source_refs`, as the `assemble` description says.
- The `jd_sha256` is the hash of the JD markdown file (the pipeline hashes `jd.txt`; WP code should treat the
  fixture file as that text).
