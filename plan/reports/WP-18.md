## Final description (667 characters)
Tailors a CV or resume to a job description and renders a truthful, ATS-friendly PDF of at most two pages plus a
match report. Accepts CVs as PDF, Markdown, or text, and job descriptions as files, pasted text, recruiter emails,
or URLs. Asks focused questions about gaps, remembers confirmed experience across runs, and shows changes for
approval. Use when the user asks to tailor, target, or ATS-optimize a CV or resume for a job, role, or JD, or when
they answer questions or give change instructions during an active CV run, for example 'yes, add SLOs to the SRE
roles'. Also checks, resumes, or re-renders runs in out/. Not for cover letters or LinkedIn profiles.

  prompt runs `cvt brief critic RUN`. The two conflict, so the prompt reads `out/RUN/briefs/critic.md` (the file
  `brief critic` writes), runs the command only if the host allows commands, and otherwise asks the parent to run
  it. `SKILL.md` tells the parent to run `cvt brief critic RUN` before invoking the subagent.
- `cvt lint-skill --all` shadows the global `--all` (cap lifting) for that command, as `approve --all` does.
- Violation JSON uses `code: "schema"` (the contract's violation enum has no lint code).
