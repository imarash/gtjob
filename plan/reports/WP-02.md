# WP-02 report: Render assets

Status: DONE

## Summary

- Fonts: Source Sans 3 (3.052R) and Libertinus Serif (v7.051) are bundled with 4 static OTF weights each. Each family
  has its upstream `OFL.txt`, and the whole folder is 2.4 MB.
- `FONTS.md` lists the version, source URL, license, Typst family name, and SHA-256 of every file. A test checks the sums
  against the files.
- `presets.json` holds exactly the interfaces.md section 9 values, and `compact` equals `floor` on the shared keys.
- `senior-render.json` (Alex Chen, draft, 4 employers, one with 3 client subentries, an earlier line, 8 certifications,
  education, one `[[CONFIRM: number of services]]`) and `junior-render.json` (Jamie Rivera, 2 roles, not draft) were
  re-verified against `render-model.schema.json` and left unchanged.
- Tests: `tests/unit/test_render_assets.py` covers schema validity, fixture shape, presets, checksums, license and size
  checks, and a Typst compile of each family with `ignore_system_fonts=True`. It reads the PDF font list with `pypdf`.

## Deviations

- Italic is `SourceSans3-It.otf` (the upstream name), as the brief allows.
- Libertinus ships Semibold, so all four weights are present.
- In Typst, each Semibold registers as its own family (`Source Sans 3 Semibold`, `Libertinus Serif Semibold`). Templates
  must select it by that name, not by `weight: 600` on the base family. This is noted in `FONTS.md`.
- The Size check in the test sums every file under `fonts/`, not only the OTFs.
